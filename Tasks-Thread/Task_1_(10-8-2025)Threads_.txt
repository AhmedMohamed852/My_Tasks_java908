🔹 Thread Sleep and Join :-

### Use Thread.sleep() 
Task 1 ===> : Print numbers 1 to 5 with a 1-second delay between each number using sleep().

        for(int i = 1 ;i <= 5 ;i++)
        {
            System.out.println("Thread " + i + " is running.");
            Thread.sleep(1000);
        }


### Use Thread.join()
Task 2 ===> : Create two threads. Make the main thread wait for them to finish using join().

        System.out.println("==============  Start Main ===============");
        Runnable runnable1 = () -> {
            for(int i = 1; i <= 5; i++) {
                System.out.println("Runnable 1 :==> " + i + " is running.");
            }};

        Runnable runnable2 = () -> {
            for(int i = 1; i <= 5; i++) {
                System.out.println("Runnable 2 :==> " + i + " is running.");
            }};

        Thread thread1 = new Thread(runnable1);
        Thread thread2 = new Thread(runnable2);
        thread1.start();
        thread2.start();
        thread1.join();
        thread2.join();

        System.out.println("==============>  Main thread finished waiting <===============");

Task 1 ===> : Create a BankAccount class shared between two types of threads:
class Bank account :-

 public class BankAccount {
    private int balance = 0;

    public synchronized void deposit(int amount) {
        balance += amount;
        System.out.println("Deposited " + amount + " to the bank");
        notify();
    }

    public synchronized void withdraw(int amount) throws InterruptedException {
        System.out.println("Trying Withdrawn " + amount + " from the bank");
        if (amount > balance) {
            System.out.println("Not enough money to withdraw from the bank\n Waiting for Deposit..........");
            wait();
        }
        balance -= amount;
        System.out.println("Withdrawn " + amount + " from the bank");
    }
}

class Withdraw :- 

public class withdraw extends Thread{
   public BankAccount account;

   withdraw(BankAccount account) {
       this.account = account;
   }

   public void run(){
       try {
           Thread.sleep(2000);
           account.withdraw(5000);
       } catch (InterruptedException e) {
           throw new RuntimeException(e);
       }
   }
}

class Depositor :-

public class Depositor extends Thread{

    private BankAccount account;


    public Depositor(BankAccount account){
        this.account = account;
    }

    public void run(){
        try {
            Thread.sleep(5000);
            account.deposit(2000);
        } catch (InterruptedException e) {
            throw new RuntimeException(e);
        }
    }
}

class Main :-

        BankAccount account = new BankAccount();

        withdraw withdraw = new withdraw(account);
        Depositor deposit = new Depositor(account);

        withdraw.start();
        deposit.start();
